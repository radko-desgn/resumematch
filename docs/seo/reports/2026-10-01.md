# SEO run — 2026-10-01

First run, so it sets the baselines that later runs compare against. Branch `seo/2026-10-01`
(pushed for review, **not merged or deployed**). All "after" numbers come from a local production
build. They are not from the live site.

## Summary

- Added the crawl basics the site lacked: `robots.txt`, `sitemap.xml`, `metadataBase` and a
  canonical on the home page.
- Added honest JSON-LD on the home page (Organization, WebSite, WebApplication with the real prices,
  FAQPage), built from `packs.ts` and the FAQ copy so it can't drift from the page.
- The home H1 is now one clean sentence for crawlers. It used to concatenate all four rotating
  phrases with no spaces.
- The hero text now paints on the first frame instead of waiting for hydration. On emulated mobile
  (4x CPU, slow 4G), LCP dropped from **4.87 s to 0.81 s**, with the same look and the same motion.
- Kept `/reset-password` and the `/preview/results` sandbox out of search, and gave each its own
  title.

## What changed

1. **`metadataBase` and canonical.** [`app/layout.tsx`](../../../frontend/app/layout.tsx) sets
   `metadataBase` (www origin) and `og:site_name`.
   [`app/page.tsx`](../../../frontend/app/page.tsx) adds a self-referencing canonical, set on the
   page rather than the root layout so other routes don't inherit it. Shared constants are in
   [`lib/site.ts`](../../../frontend/lib/site.ts).
2. **robots.txt and sitemap.xml.** [`app/robots.ts`](../../../frontend/app/robots.ts) allows
   everything and links the sitemap. Pages that must stay out of the index use `noindex`, not
   `Disallow`, so crawlers can still read that tag.
   [`app/sitemap.ts`](../../../frontend/app/sitemap.ts) lists only `/`, the one indexable URL
   today. It has no fake `lastModified`.
3. **Utility pages kept out of search.**
   [`app/reset-password/layout.tsx`](../../../frontend/app/reset-password/layout.tsx) and
   [`app/preview/results/layout.tsx`](../../../frontend/app/preview/results/layout.tsx) set
   `noindex` and their own titles. Both pages are client components, so the metadata lives on the
   segment layout.
4. **Structured data.** [`lib/structuredData.ts`](../../../frontend/lib/structuredData.ts),
   rendered in `app/page.tsx`, contains:
   - Organization (logo, Instagram `sameAs`)
   - WebSite
   - WebApplication, with one `Offer` per pack from `lib/packs.ts`. Offers are omitted while
     `COMING_SOON` is on.
   - FAQPage

   The FAQ copy moved verbatim to [`lib/faq.ts`](../../../frontend/lib/faq.ts), and
   [`FAQ.tsx`](../../../frontend/components/landing/FAQ.tsx) imports it. That keeps the page and the
   schema identical. A server component can't read constants out of a `"use client"` module.
   **There is no AggregateRating or Review schema**, because there are no real reviews.
5. **Hero: clean H1 and first-frame paint.**
   - [`RotatingText.tsx`](../../../frontend/components/landing/RotatingText.tsx): the invisible
     sizer spans draw their phrase with `::before` from `data-text`. They still reserve the same
     box (measured identical at 360/412/768/1350 px in Chromium and WebKit), but they are no
     longer part of the heading text.
   - [`Hero.tsx`](../../../frontend/components/landing/Hero.tsx): word spaces between the three H1
     lines. The hero entrances (fade-rise of the text block and wizard, masked rise of the H1
     lines) moved from framer-motion to CSS (`.mk-rise` / `.mk-line` in
     [`globals.css`](../../../frontend/app/globals.css)), with the same durations, delays and
     easing. The CSS runs from the first paint and respects reduced motion like the other
     motion-kit effects.
   - The fade starts at `opacity: 0.01`, as `mk-roll` already does. A version starting at 0
     measured LCP at the *end* of the fade (+0.5 s mobile, +0.9 s desktop), because Chrome ignores
     invisible paints and a compositor-run fade doesn't repaint.
   - Fill mode is `backwards`, so no transform is left behind to trap fixed-position children.
   - The logo intro is untouched and still doesn't block LCP. All LCP runs below were first visits
     with the intro playing.

The H1 wording, layout, colours and motion are unchanged. No visible copy changed.
