<objective>
## Goal
Build the headless core of ResumeMatch: a Python package that takes a resume + job posting (plain text) and returns a structured analysis object containing (1) a calibrated fit score, (2) an evidence-backed gap analysis, and (3) rewritten bullets — powered by Claude Haiku 4.5 with schema-validated JSON output and local `bge-small` embeddings for requirement↔resume matching. No UI in this plan; the engine must be runnable and provable from a CLI/test.

## Purpose
This is the value core of the whole project (PROJECT.md "Core Value"). Proving the analysis engine works end-to-end headlessly de-risks everything downstream — the Streamlit UI (01-02), the eval harness (Phase 2), and persistence (Phase 3) all sit on top of this. Doing it headless-first means it's testable and cheap to iterate.

## Output
An installable `resumematch/` package with a working `analyze(resume, job)` function and a `python -m resumematch.cli` entrypoint that runs the full analysis on sample fixtures and prints valid structured output.
</objective>

## AC-2: Scoring + gap analysis returns valid, evidence-grounded structured output
```gherkin
Given a resume and a job posting as text
When I call the scoring function
Then it returns a schema-validated object with overall_fit_score (0-100), a verdict, a summary, and a requirements list where each item has type (must-have/nice-to-have), status (met/partial/missing), and evidence that is either an exact quote from the resume or null when status is missing
```

## AC-3: Bullet rewriting returns tailored bullets with no fabrication
```gherkin
Given a set of resume bullets and a target job
When I call the rewriting function

```

```gherkin
Given the extracted job requirements and the resume split into chunks
When the local bge-small embedder runs

```
